STATIONKEEPER MACROS 1.4.0
A menu and a bookshelf for the macros in a Word template. It never edits your code.

1. TRY IT ON A COPY OF YOUR TEMPLATE FIRST.

2. ADD IT TO THE TEMPLATE (no VBA editor needed)
   - If this file came by email, Teams or the web: right-click "Stationkeeper Macros Kit.dotm"
     > Properties > tick Unblock > OK.
   - Word: File > Open "Stationkeeper Macros Kit.dotm". Enable macros if asked.
   - View > Macros > StationkeeperMacrosInstall > Run. Pick your template (closed, or open and saved).
   - Or in the VBA editor: File > Import File, the three files in "Import files"
     (keep each .frx beside its .frm).

3. DESCRIBE YOUR MACROS (the admin)
   - Open your template itself (File > Open the .dotm).
   - View > Macros > StationkeeperMacrosAdmin > Run.
   - The list shows each macro with two columns: In menu (Shown, Hidden, Not set)
     and Description (Written, Missing).
   - Pick each macro: title, description, category, keywords, what it affects,
     and whether it changes the document.
     Tick "Show in the menu".
   - Many macros? Keep a primary list: Bulk tools > Export the list to Excel, edit it,
     then Bulk tools > Update from the primary list. It shows what will change first.
     Any Excel, CSV, Word table or JSON list works (Update from a list file).
     Blank cells leave values as they are.
   - Settings tab: set Alt+Shift+M, an Add-ins tab button, and where backups go.
   - Tick Ready to save, then Save to template. A dated backup is made first.
     The first time, it asks where backups should go.
   - Test column: Test this macro, or Bulk tools > Test every macro. Tests run on a
     scratch document. If Word shows an error, click End: the macro shows Failed.
   - Bulk tools > Check the code health: missing libraries and risky lines.

4. USE THE MENU
   - In any document based on the template: Alt+Shift+M, the Add-ins tab button,
     or View > Macros > StationkeeperMacros.
   - Type to search. Up/Down move, Enter runs, Esc closes.
   - One Ctrl+Z undoes a whole macro.
   - Show: All macros, Stationkeeper, Other, Needs effort data, Ready to run now.
     Category: one of your categories.
     An outlined diamond SK means built for Stationkeeper (runs on its own); a filled
     diamond SK means it needs Stationkeeper data.
   - The strip under the list shows the linked Stationkeeper effort folder.
     Link a folder... (or Change...) picks it once; Refresh reads it again; Unlink stops.
     Pick the folder Stationkeeper saves the effort to (it holds "Stationkeeper Data").
     Once linked, the tools use the effort's rules first, then the standards workbook,
     then their defaults. Each report says which rules it used.
     Open the menu from a document inside an effort folder and it offers that folder
     (Use this folder). It also warns when a synced effort folder is not kept on this
     device, a file is online-only, or OneDrive kept conflicting copies.

IF THE ADMIN SAYS WORD IS NOT LETTING IT LOOK INSIDE THE TEMPLATE
   Turn on File > Options > Trust Center > Trust Center Settings > Macro Settings >
   "Trust access to the VBA project object model", then open the admin again.
   Only the person running the admin needs this. The menu never does.
   Or: export your module(s) from the VBA editor (right-click > Export File) and use
   Bulk tools tab > Read macros from .bas files.

STATIONKEEPER TOOLS (checks and fixes for Word documents)
   - Open the kit, View > Macros > StationkeeperToolsInstall > Run, pick the template.
   - Open the template: the tools are in the menu already described. Save once in the admin.
   - Run MakeStandardsWorkbook (or ChooseStandardsWorkbook for a shared one) to set
     your team's allowed styles, table types and placeholders in Excel.
   - Reports open as a new document and change nothing. Fixes are one Ctrl+Z.
   - On SharePoint/OneDrive files with AutoSave on, fixes wait; reports run.
   - PowerPoint fixes (Deck Conform to Template, Font Fix, Slide Number Fix, Banned
     Phrases Fix, Remove Unused Layouts) never change the open deck: they save a copy
     beside it. Set DeckTemplate on the Settings sheet to your team's .potx first.
   - Deck Media List lists pictures, videos, charts and SmartArt by slide and renames them.

TO TAKE IT OUT
   Open the kit, run StationkeeperMacrosRemove (or StationkeeperToolsRemove), pick the template.
   Your macros and the descriptions stay.
